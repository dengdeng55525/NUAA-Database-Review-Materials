# NUAA-Database-Review-Materials

数据库系统概论课程复习资料归档，整理了本人学习期间使用过的 4 份 PDF，涵盖大题解题方法、范式级别判断、选填题知识点和 SQL 语言。

## 基本信息

- 课程：数据库系统概论
- 资料来源：Bilibili UP 主 **没睡醒冬**
- 资料形式：PDF，共 4 份、36 页

这些资料是我找到并使用过的数据库复习材料，在此整理为统一入口，方便同学们查阅。感谢原作者的整理与分享！

## 来源说明

- UP 主主页：[没睡醒冬（UID：949043）](https://space.bilibili.com/949043)
- 对应视频：[【数据库系统概论】三小时复习期末速成不挂科](https://www.bilibili.com/video/BV1Bq4y1Y7GC/)

视频围绕大题解题方法和各章节选填题知识点展开，原作者在视频简介中说明课件可从评论区获取。本仓库保留所收集 PDF 的原文件名和内容，资料作者归属及使用授权以原作者说明为准。

## 资料内容

| 文件 | 页数 | 主要内容 |
| --- | --- | --- |

## 使用方式

使用浏览器或 PDF 阅读器打开文件即可。可结合原作者的视频学习，再按照课程教材、课堂要求和练习题巩固相关知识。

建议先用 `选填题知识点.pdf` 梳理知识框架，再结合 `大题解题方法.pdf` 和 `范式级别判断.pdf` 练习关系理论与大题，最后用 `SQL语言.pdf` 对照练习 SQL 语句。
